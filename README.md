# 见岸

把材料留下，把思路学明白。

见岸是本地学习工作台：导入材料、剪藏板书，与 AI 对照学习，留下讲解和自己的学习页。此仓库只托管安装包与更新信息，应用源码保存在私人仓库。

## 首批内测 · 1.0.46

[下载与版本说明](https://github.com/CoooF/jianan-releases/releases/tag/v1.0.46)

当前提供 Apple 芯片 Mac（arm64）安装包。Windows 包尚未完成真实安装验证。

1. 下载 DMG，将应用拖入 Applications。
2. 首次打开创建学习库，或从已有完整备份恢复。
3. 输入作者通过微信提供的激活码，再配置自己的 Pi 模型。也可以稍后激活，先阅读和整理材料。

无需注册账号。默认一个码最多绑定两台安装，作者可设置有效期、停用或解绑；安装身份尚不是硬件防复制。在线授权最多缓存七天，设备联网后可刷新。

模型调用由使用者自己的模型配置承担，见岸不设置次数或 Token 配额。学习库、附件和模型密钥保存在本地；激活服务只接收授权与设备标识。

## 更新与备份

设置中可以检查更新、查看改动并下载，客户端校验签名、大小和 SHA256。下载完成后打开安装包位置，由你手动安装；此版不会自动重启正在运行的 AI 任务。

安装或更新前，请先在应用中创建完整学习库备份。从开发版首次迁移，在原版备份后，在此版恢复。完整学习库备份不包含个人模型密钥或授权身份，换电脑需要重新配置与激活。

这是内测包，采用稳定本地自签名，尚未 Apple 公证。若 macOS 阻止打开，请把提示截图发给作者。

请勿在公开 Issues 中提交激活码、API Key 或私人学习库。
