# 见岸

把材料留下，把思路学明白。

这是见岸的安装包与更新信息仓库。应用源码保存在独立的私人仓库。

## 当前状态

正在准备首批内测发布。激活服务、macOS 分发包和首开引导仍在联调，**当前没有公开发布可安装的正式版本**。

后续安装包将放在本仓库的 Releases。应用内支持检查版本、查看改动和下载校验后的安装包；安装由使用者手动开始。

## 内测使用

- 不需要注册账号，测试授权由作者单独分发。
- 学习库、附件与个人模型密钥保存在本地。
- 模型由使用者按 Pi 配置；见岸不设置模型调用次数或 Token 配额。
- 安装或更新前请先在应用里创建完整学习库备份。

请勿在公开 Issues 中提交激活码、模型密钥或个人学习库。
