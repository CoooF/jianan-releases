# 见岸 · 安装包与更新

见岸帮助把网盘跟课时的截图、课件、老师文稿和 AI 讲解留在自己的学习库中。

[下载当前 Mac 内测版 1.0.48](https://github.com/CoooF/jianan-releases/releases/tag/v1.0.48)

适合 Apple Silicon（M 系列）Mac，DMG 约 284 MB。应用名称「见岸」。打开 DMG 拖到 Applications，再打开应用，按欢迎页新建学习库、输入测试激活码、配置自己的 Pi 模型。测试激活码由作者通过微信分发。

当前内测包尚未经过 Apple Developer ID 签名和公证。首次如果被 macOS 拦截，先尝试打开，再到「系统设置 → 隐私与安全性」点击见岸对应的「仍要打开」，按系统提示确认。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

1.0.48 修复安装后误读开发库与建库位置受限：首次从欢迎页开始，学习库可自选本地专用文件夹，普通重启记住所选库；缺失库提示找回，旧核心库升级沿用副本。

已有内容请先完整备份，退出应用后把新「见岸.app」拖入 Applications，选择替换。从误读开发库的 .46/.47 切换时，在新版欢迎页恢复完整备份；原开发库/密钥/激活不自动迁移，正式配置需本人重新填写。应用支持更新提醒、下载进度与签名/SHA256 校验；当前仍需手动安装。

此仓库仅分发安装包、版本说明与签名更新清单，不包含见岸应用源码。源码保存在私有仓库。Windows 和 Intel Mac 包尚未在此发布。
